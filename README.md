# Tabular

**Tabular** é uma ferramenta poderosa e intuitiva para criação, edição e exportação de tabelas em PDF para serem importadas em projetos latex ou em outras aplicações. Desenvolvido com foco em performance e usabilidade, oferece uma experiência próxima a editores de desktop diretamente no navegador.

## Funcionalidades Principais

### 🚀 Edição Avançada de Tabelas
- **Manipulação Completa**: Insira e exclua linhas e colunas com facilidade.
- **Mesclagem e Divisão**: Mescle células selecionadas ou divida células existentes horizontalmente e verticalmente.
- **Seleção Inteligente**: Selecione células individuais, faixas de células, ou linhas e colunas inteiras para edição em massa.

### 📝 Formatação Rica
- **Estilização de Texto**: Aplique Negrito e Itálico rapidamente.
- **Alinhamento**: Controle total sobre o alinhamento do texto (Esquerda, Centro, Direita).
- **Cores**: Personalize a cor de fundo das células com um seletor de cores integrado.

### 🔢 Suporte a LaTeX
- **Equações Matemáticas**: Renderização nativa de equações LaTeX. Basta envolver seu código entre `$$` (ex: `$$E=mc^2$$`) para visualizar fórmulas matemáticas complexas perfeitamente renderizadas (via KaTeX).

### 📋 Importação Inteligente (Área de Transferência)
- **Copiar e Colar do Word/Office**: Cole tabelas diretamente do Microsoft Word, Excel, LibreOffice ou páginas web.
- **Preservação de Estrutura**: Mantém spans de linha e coluna (rowspan/colspan) originais.
- **Imagens**: Suporte para colar imagens contidas dentro das células da tabela.

### 📄 Exportação Profissional
- **PDF Pixel-Perfect**: Exporte sua tabela como um documento PDF de alta qualidade, preservando layout, fontes e cores, pronto para impressão ou relatórios.

### ⚡ Produtividade
- **Histórico (Undo/Redo)**: Edite sem medo com sistema robusto de desfazer e refazer alterações.
- **Atalhos de Teclado**: Suporte a atalhos comuns (Ctrl+Z, Ctrl+Y, etc.).

## Tecnologias

Construído com tecnologias modernas para garantir rapidez e robustez:
- **React JS** & **TypeScript**
- **Vite** para desenvolvimento ultra-rápido
- **Tailwind CSS** para estilização eficiente
- **Zustand** para gerenciamento de estado
- **KaTeX** para renderização matemática
- **jsPDF** & **html2canvas** para geração de PDF
